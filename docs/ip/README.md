# IP y evidencia de I+D

Este directorio preserva la historia técnica real de SocialPro. No determina
por sí solo quién es el propietario jurídico, qué gasto es fiscalmente
deducible ni qué beneficio puede acogerse a un régimen IP Box.

Documentos:

- [`IP_PROVENANCE.md`](./IP_PROVENANCE.md): fotografía de la IP preexistente a
  1 de septiembre de 2026 y asuntos de titularidad que deben acreditarse.
- [`IP_BOX_READINESS.md`](./IP_BOX_READINESS.md): requisitos, estado actual,
  bloqueos y hoja de ruta para KekoPilot/Cyprus.
- [`RD_EVIDENCE_POLICY.md`](./RD_EVIDENCE_POLICY.md): reglas para registrar
  actividad técnica, tiempo, coste real, ahorro e ingresos sin mezclarlos.
- [`HISTORICAL_CONTRIBUTOR_PROTOCOL.md`](./HISTORICAL_CONTRIBUTOR_PROTOCOL.md):
  protocolo para reconstruir de forma veraz una colaboración histórica y
  entregarla a asesores laborales, fiscales y de propiedad intelectual.

Plantillas:

- [`CONTRIBUTOR_EVIDENCE_PACKET.md`](./templates/CONTRIBUTOR_EVIDENCE_PACKET.md):
  expediente individual de hechos y evidencias.
- [`ADVISOR_DECISION_RECORD.md`](./templates/ADVISOR_DECISION_RECORD.md):
  registro de la decisión profesional que autoriza cualquier regularización.
- [`HISTORICAL_TIME_RECONSTRUCTION.csv`](./templates/HISTORICAL_TIME_RECONSTRUCTION.csv):
  hoja de reconstrucción de actividad; registra rangos y fuentes, no horas
  inventadas.

## Reglas

1. No reescribir, borrar ni backdatear historia para presentar trabajo antiguo
   como desarrollo nuevo.
2. Todo el código y conocimiento existentes antes de constituir la futura
   sociedad chipriota se etiquetan `PRE-CYPRUS` hasta que exista asesoramiento
   y documentación jurídica que dispongan otra cosa.
3. Git prueba actividad técnica; no prueba por sí solo propiedad, horas ni
   gasto fiscal.
4. La IA solo propone clasificaciones. Un profesional fiscal aprueba o rechaza
   cualquier tratamiento tributario.
5. KekoPilot y SocialPro pueden compartir conceptos o APIs sin que eso
   convierta automáticamente la IP de SocialPro en propiedad de KekoPilot.
