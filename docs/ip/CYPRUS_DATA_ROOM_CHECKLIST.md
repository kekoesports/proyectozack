# Data room PRE-CYPRUS

## Ubicación privada

Carpeta maestra: `KekoPilot — Expediente IP (PRE-CYPRUS)` en Google Drive.

La carpeta `07 — Cyprus Ltd (FUTURO — no constituida)` debe permanecer vacía de
documentos societarios hasta que la sociedad exista. Un borrador o una propuesta
de asesor se archiva en `06 — Asesores España y Chipre`.

## Reglas

1. No guardar contraseñas, secretos API, semillas, recovery codes ni códigos
   2FA.
2. Conservar el original firmado y registrar toda sustitución como una nueva
   versión.
3. No renombrar un borrador como contrato firmado ni atribuir una fecha que no
   conste en el documento.
4. Un enlace en el CRM acredita localización; un SHA-256 acredita integridad;
   ninguno prueba por sí solo validez jurídica o fiscal.
5. Los documentos sensibles permanecen privados. Las políticas no sensibles
   pueden conservarse también en Git con un commit inmutable.
6. Solo un asesor identificado puede justificar el estado
   `advisor_approved`.
